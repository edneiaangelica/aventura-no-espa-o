# aventura-no-espa-o

Jogo pedagógico de matemática para os anos iniciais do Ensino Fundamental.

## Perdidos no Espaço

Experiência gamificada com 3 missões progressivas:

1. **Energia da nave**: adições básicas para religar o painel.
2. **Mapa estelar**: deslocamentos e coordenadas em malha quadriculada.
3. **Combustível**: adições com números maiores e estratégias de cálculo mental.

### Mecânicas implementadas

- Cronômetro de **1 minuto por questão**.
- Progressão por missões com **acerto mínimo para avançar**.
- Feedback imediato de vitória/erro e opção de tentar novamente.
- Indicadores visuais de progresso para energia e combustível.
- Layout responsivo para uso em celular, computador e TV.

### Como executar

Abra o arquivo `/home/runner/work/aventura-no-espa-o/aventura-no-espa-o/index.html` em qualquer navegador moderno.
